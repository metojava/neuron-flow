CURRENT API / ml

Classical machine learning

About this page. Unlike the three historical documents in this reader, this page describes the current ml package. It is a short reference; the full chapter with derivations, parameter tables and exercises is newbook chapter 16.

The neural-network stack works on float[] and float[][]. The ml package works on named, typed columns: mixed numeric and categorical features, missing values, train/test splits, linear models, trees, kernels and clustering. It borrows scikit-learn's vocabulary — estimator, transformer, pipeline — without hiding the math.

Why a second API?

Tabular data has different requirements. A spreadsheet column may be numeric or categorical, may be missing, and may have a scale wildly different from its neighbour. A linear model or an SVM cannot absorb raw strings or features measured in thousands, while a neural network can. The ml package therefore makes preprocessing a first-class object and validates schemas instead of silently reshaping arrays.

PackageData typeBest forEntry point
layersfloat[], float[][]Images, dense and convolutional networksNeuralNetwork
autograd, transformersfloat tensorsSequence models and custom graphsTensor, Ops

The two numeric worlds are deliberate: classical models use double for numerically sensitive linear algebra, and the neural stack uses float for SIMD throughput. Convert at the boundary with DataFrame.toDoubleMatrix() and your own float loop. The packages do not depend on each other.

DataFrame and Vector

ml.DataFrame is an immutable, column-oriented table. Every column is either NUMERIC (a double[], with Double.NaN marking missing values) or CATEGORICAL (a String[], with null marking missing values). Accessors return defensive copies, so a frame can be shared across pipeline stages without aliasing bugs.

DataFrame raw = DataFrame.builder(4)
        .addNumeric("age",    new double[]{34, 51, Double.NaN, 28})
        .addNumeric("income", new double[]{62_000, 91_000, 47_000, Double.NaN})
        .addCategorical("city", new String[]{"Paris", "Berlin", null, "Paris"})
        .addCategorical("plan", new String[]{"premium", "basic", "premium", null})
        .build();

int rows = raw.rows();          // 4
int columns = raw.columns();    // 4
double age = raw.getDouble(0, 0);
String city = raw.getString(0, 2);
double[] ages = raw.numericColumn(0);
int cityIndex = raw.columnIndex("city");

ml.Vector is the matching immutable target container. Labels are double, so 0/1, -1/+1 and arbitrary class ids all work. Useful methods include get, take, toArray, count, uniqueSorted, mean and requireFinite.

Preprocessing

Every transformer implements the same contract: fit learns parameters, transform applies them (including to unseen data), fitTransform does both, and isFitted reports state. Calling transform before fit throws IllegalStateException.

ClassLearnsNotes
SimpleImputerPer-column mean, median or most frequent valueStrategy.MEAN, MEDIAN, MOST_FREQUENT; categories use the mode.
OneHotEncoderSorted category dictionariesdropFirst avoids collinearity; unknown values throw (ERROR) or become all zeros (IGNORE).
StandardScalerMean and population standard deviationConstant columns keep scale 1.
MinMaxScalerColumn minimum and maximumMaps to a configurable range, default [0, 1].
PipelineFits each stage on the output of the previous onePipeline.of(...) or then(...); prevents leakage such as scaling before imputation.

Splitting and metrics

DatasetSplit.Split split = DatasetSplit.split(raw, labels, 0.25, 42L);
DataFrame train = split.train();
DataFrame test  = split.test();
Vector yTrain   = split.yTrain();
Vector yTest    = split.yTest();

double accuracy = Metrics.accuracy(yTest, predictions);
double mse      = Metrics.meanSquaredError(yTest, predictions);
double r2       = Metrics.r2Score(yTest, predictions);

The split is a deterministic shuffle for a given seed. It keeps rows intact and makes no attempt to stratify; for imbalanced labels, split by class yourself or use the fold helpers in data.cv on the neural-network side.

Models

Supervised models implement fit(DataFrame, Vector), predict, predictProbabilities and score. Classifiers also expose classes(). Regressors return a single probability column equal to the point prediction.

ModelTaskKey configuration
LinearRegressionRegressionLearning rate, epochs, L2 penalty, tolerance, batch size, intercept.
LogisticRegressionBinary and multiclass classificationShuffled mini-batch SGD (default batch 32); one sigmoid model per class; L2 penalty.
DecisionTreeClassificationCriterion.GINI or ENTROPY, depth, minimum samples, random feature subset, seed.
RandomForestClassificationNumber of trees, per-tree depth and feature sampling, seed; exposes feature importances.
SVMBinary classificationLinear or RBF kernel, c, tolerance, maximum passes; one-vs-rest for multiclass.
KMeansClusteringk, iterations, tolerance, restarts, seed; exposes centres and inertia.

Kernels live in ml.kernel: Kernel.linear() and RbfKernel.withDefaultGamma(int featureCount). Models never standardise implicitly; put a scaler in the pipeline.

End-to-end pipeline

DataFrame raw = DataFrame.builder(rows)
        .addNumeric("age", age)
        .addNumeric("income", income)
        .addNumeric("score", score)
        .addCategorical("city", city)
        .addCategorical("plan", plan)
        .build();
Vector labels = Vector.of(purchased);

DatasetSplit.Split split = DatasetSplit.split(raw, labels, 0.25, 42L);

Pipeline pipeline = Pipeline.of(
        new SimpleImputer(SimpleImputer.Strategy.MEAN),
        new OneHotEncoder(),
        new StandardScaler());
DataFrame train = pipeline.fitTransform(split.train());
DataFrame test  = pipeline.transform(split.test());

LogisticRegression model = new LogisticRegression(0.2, 3_000, 0.0, 1e-10, true)
        .fit(train, split.yTrain());
double accuracy = Metrics.accuracy(split.yTest(), model.predict(test));
double[][] probabilities = model.predictProbabilities(test);

Fit the pipeline on training rows only, then transform the test rows with pipeline.transform. Fitting on the full frame before splitting leaks test statistics into training and inflates the score.

Regression and clustering

DataFrame houses = DataFrame.ofNumeric(new String[]{"area", "bedrooms"}, features);
Vector prices = Vector.of(pricesArray);
DatasetSplit.Split split = DatasetSplit.split(houses, prices, 0.25, 42L);

Pipeline pipeline = Pipeline.of(new StandardScaler());
DataFrame train = pipeline.fitTransform(split.train());
DataFrame test  = pipeline.transform(split.test());

LinearRegression regression = new LinearRegression(0.1, 5_000, 0.0, 1e-12, true)
        .fit(train, split.yTrain());
double rmse = Math.sqrt(Metrics.meanSquaredError(split.yTest(), regression.predict(test)));

KMeans kmeans = new KMeans(3, 300, 1e-6, 10, 42L);
int[] labels = kmeans.fitPredict(pipeline.transform(houses));
double[][] centres = kmeans.clusterCenters();
double inertia = kmeans.inertia();

Run the bundled demonstration with java -cp target/classes examples.ClassicalMlDemo (add --add-modules jdk.incubator.vector when running outside Maven). It builds synthetic mixed-type data, then reports roughly 0.95 logistic, 0.93 SVM, 0.85 tree and 0.94 forest accuracy on the held-out split, an R² of about 0.89 for house prices, and three recovered k-means clusters.

Status and limits

  • The package is binary/multiclass classification, regression and k-means only. There is no PCA, no feature selection, no gradient-boosted trees and no model persistence.
  • Logistic and linear regression use shuffled mini-batch SGD (default batch 32), not coordinate descent or L-BFGS. Convergence is controlled by epochs and tolerance, not by an exact solver.
  • The tree is axis-aligned and uses exhaustive split search over observed values; it is not optimised for very wide frames.
  • The SVM is SMO with a linear or RBF kernel; multiclass is one-vs-rest, so probabilities are not calibrated.
  • DataFrame is immutable and copies on access. This is safe but allocates; it is not intended for multi-gigabyte tables.
  • There are unit tests for the data frame, preprocessing, supervised models and k-means under src/test/java/ml.
