The NFS text collection

About these documents. The first three documents are formatted copies of the original text. They describe earlier or proposed versions of the library, so class names, packages, commands, and features may differ from the current code. Equations are displayed in simplified notation; the original LaTeX appears when hovering over display equations. The fourth page, Classical ML, documents the current ml package and is not a historical copy.

Three original text files, formatted for comfortable reading, plus a current reference for the classical machine-learning API. Browse the tutorial, study the implementation notes, inspect the original Java listings, or read about DataFrame, pipelines, trees, SVMs and k-means.
