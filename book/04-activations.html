04 · Activations

Make the network nonlinear

Without nonlinear activations, stacking dense layers still produces a single affine transformation. Nonlinearity lets the network represent richer relationships such as XOR.

FunctionOutput and derivativeTypical role
Sigmoid1/(1+e−z); y(1−y)Binary output in (0,1); saturation can make gradients small.
Tanhtanh(z); 1−y²Hidden layers with outputs between −1 and 1; also saturates.
ReLUmax(0,z); 1 for positive values, otherwise 0Common hidden activation; inactive neurons can stop receiving gradients.
Leaky ReLUz if z ≥ 0, otherwise αz; derivative 1 or αKeeps a slope on the negative side when α > 0.
Linearz; derivative 1Unbounded output, often useful for regression.

At the non-differentiable point z = 0, the library chooses 0 for ReLU and α for leaky ReLU. It computes derivatives from the activated output. For leaky ReLU with α = 0, negative inputs and zero both produce zero, matching the chosen slope. The sigmoid implementation uses separate formulas for positive and negative inputs to reduce overflow.

ActivationFunction[] acts = {
    ActivationFunction.linear(), // input slot; inputs are copied directly
    ActivationFunction.tanh(),
    ActivationFunction.sigmoid()
};

Choosing functions

Use sigmoid for a single binary probability-like output and linear for an unbounded numeric prediction. ReLU or leaky ReLU are common hidden choices, while tanh can be useful for small examples. Always match the loss to the output’s meaning. The interface operates on individual scalar values, so coupled functions such as softmax require changes to the design and its backward pass.

Initialization. The default constructor uses uniform Xavier-style weights in [−√(6/(fan-in+fan-out)), +√(6/(fan-in+fan-out))] and zero biases. Pass WeightInitializer.heNormal() to the six-argument constructor for He normal initialization, commonly used with ReLU.
