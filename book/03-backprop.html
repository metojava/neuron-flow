03 · Backpropagation

Learning from a mistake

Backpropagation answers a practical question: “Which weights should change, and in which direction, to make this prediction a little better?”

First, forget the symbols

Imagine a network predicts 0.60, but the right answer is 1.00. A loss function gives this mistake a score. A higher score means a worse prediction.

The network has many little adjustable knobs: its weights and biases. Backpropagation works backwards from the mistake and asks, for each knob: “If I turn this knob up just a tiny bit, will the loss go up or down, and by how much?”

That answer is called a gradient. A positive gradient means increasing the knob would increase the loss, so the optimizer usually moves the knob down. A negative gradient means increasing the knob would decrease the loss, so the optimizer moves it up. A gradient near zero means a tiny change to that knob has little immediate effect on the loss. This is a local guide, not a guarantee that a large step will help.

Simple analogy. If you are walking down a hill in fog, the slope under your feet tells you which way is locally downhill. A gradient gives the optimizer similar local information about the loss.

What is ∂?

The symbol ∂ is read “partial derivative.” It is a compact way of describing a slope when several things can affect a result. For example, ∂L/∂w means: “How quickly would the loss L change if we increased weight w by a tiny amount, while keeping the other weights fixed?” You can read it as “change in loss per tiny change in weight.”

For intuition, if increasing a weight by 0.01 increases loss by approximately 0.002, the slope is approximately 0.002 / 0.01 = 0.2. The exact derivative describes what happens as that change gets extremely small.

The chain rule in everyday language

A weight does not normally change the loss directly. It first changes a neuron’s weighted sum; that changes the neuron’s output; that changes later outputs; eventually the prediction and loss change.

Change a weight→Change a sum→Change an output→Change the loss

For a small change, we find the effect of the whole chain by multiplying the effects of its links. For example, if increasing A by 1 would increase B by 2, and increasing B by 1 would increase C by 3, then increasing A by a small amount increases C by roughly six times that amount. That multiplication is the chain rule. For nonlinear functions the slopes are evaluated at the current values, so this is a local approximation.

One output neuron: follow a real number

In the previous chapter, the input is 1, the hidden neuron output is about 0.622459, and the network predicts 0.598199. The target is 1. The output neuron takes the hidden value, multiplies it by output weight 0.8, adds bias −0.1, and applies sigmoid. The loss is squared error: (prediction − target)², about 0.161444.

  1. Start at the prediction. The slope of squared error with respect to the prediction is 2 × (0.598199 − 1) ≈ −0.803602. This says that increasing the prediction a little would lower the loss.
  2. Move one step backwards through sigmoid. At this output, sigmoid has slope output × (1 − output) ≈ 0.240357. Multiply the two slopes: −0.803602 × 0.240357 ≈ −0.193151. This is the loss slope with respect to the output neuron’s weighted sum, before sigmoid.
  3. Reach the output weight. Increasing that weight changes the weighted sum by the hidden output, 0.622459, per unit of weight. So the weight gradient is −0.193151 × 0.622459 ≈ −0.120229.
  4. Reach the output bias. Increasing the bias by a tiny amount increases the sum by the same amount. Its gradient is therefore −0.193151.

Both gradients are negative: increasing either parameter slightly would lower this particular example’s loss. With a learning rate of 0.1 and plain SGD, the output weight changes from 0.8 to about 0.812023. The update is weight = weight − learningRate × gradient; subtracting a negative number increases the weight.

What happens at a hidden neuron?

Now continue backward. The hidden output affects the output neuron’s sum through weight 0.8. Multiply the output neuron’s sum gradient by that weight: −0.193151 × 0.8 ≈ −0.154521. Then multiply by the hidden sigmoid’s slope, about 0.235004. The result is about −0.036313: the loss slope for the hidden neuron’s weighted sum.

The hidden weight receives input 1, so its gradient is −0.036313 × 1 = −0.036313. Its bias gradient is also −0.036313. In a wider network, a hidden neuron feeds multiple neurons in the next layer. Each route contributes to the loss, so we add those contributions together before applying the hidden activation’s slope.

Where does this appear in Java?

The library uses neuron.gradient to store the loss slope for that neuron’s weighted sum. It is an intermediate value used to calculate weight and bias gradients; it is not itself the gradient of every weight.

// 1. At the output: how loss changes with prediction,
//    multiplied by how prediction changes with the sum.
neuron.gradient = outputGradient[i] *
    activations[last].derivativeFromOutput(neuron.value);

// 2. At a hidden neuron: add the effects of all outgoing paths.
sum += nextNeuron.gradient * nextNeuron.weights[i];
neuron.gradient = sum *
    activations[l].derivativeFromOutput(neuron.value);

// 3. For each connection: sum-gradient × input to that connection.
gradients[k++] += neuron.gradient * previous.neurons[j].value;
gradients[k++] += neuron.gradient; // bias

These excerpts are simplified from trainBatch; last stands for the output layer index. The method repeats the calculation for each example in a mini-batch, averages the parameter gradients, then asks the optimizer to update the parameters once. It computes all gradients before changing any weights.

Optional: connect the symbols to the explanation

In many textbooks, L means loss, z is a neuron’s weighted sum, a is its output after activation, and δ (delta) is a shorthand for the loss slope with respect to that sum. In this library, neuron.gradient stores δ.

Read ∂L/∂z = (∂L/∂a) × (∂a/∂z) as: the effect of the sum on the loss equals the effect of the output on the loss, multiplied by the effect of the sum on the output. For a weight, multiply that sum gradient by the input feeding the connection. For a bias, use the sum gradient directly. These expressions describe the same steps you just calculated above.

Try it yourself

Keep the same forward values, but imagine the target is 0. Would increasing the prediction improve or worsen squared error? The slope 2 × (prediction − target) is now positive, so increasing the prediction would increase the loss. Follow that positive sign through the same positive sigmoid slope and hidden output: the output weight gradient is positive, so plain SGD decreases the weight.
