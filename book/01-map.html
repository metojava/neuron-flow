01 · The map

Meet the network

A network is a function with adjustable parameters. Training changes those parameters so the function better matches examples.

Package layout

Classes live under org.example.deeplearning. The core package holds the network, layer and neuron; activation, loss and optim hold learning components; training holds the trainer; data holds MNIST loading and downloading; and examples contains the runnable programs.

The pieces

ClassResponsibility
NeuronStores incoming weights, bias, current output value and backward gradient.
LayerGroups neurons at one depth.
NeuralNetworkBuilds layers, runs prediction, computes gradients and updates parameters.
ActivationFunctionTransforms a weighted sum and supplies its derivative from the output.
LossFunctionCalculates the cost of a prediction and its gradient with respect to predictions.
Optimizer, SGD, AdamUse gradients to update the flattened parameter array.
TrainerHolds epoch count, batch size, shuffling option and random generator.
Main, MNISTRunnerDemonstrate XOR and handwritten digit classification.

Shapes tell the story

int[] topology = {2, 8, 1};
// 2 inputs → 8 hidden neurons → 1 output
// parameters = (2 × 8 + 8) + (8 × 1 + 1) = 33

Each hidden neuron receives both inputs and has two weights and one bias. The output neuron receives eight values, one from each hidden neuron, and has eight weights and one bias. The input layer stores values, but has no trainable incoming parameters.

In this implementation, the activation array has one entry per topology entry. The first entry is conventionally linear, but the forward pass copies inputs directly and does not apply it.

One cycle

  1. Compute activations from the input to the output.
  2. Compare the prediction with the target using a loss.
  3. Apply the chain rule backwards to calculate each parameter’s gradient.
  4. Average gradients over a mini-batch and let the optimizer update the parameters.

The network stores the latest activations and gradients inside its neurons; prediction therefore changes internal state, so concurrent calls on the same instance need external coordination.
