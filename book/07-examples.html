07 · Examples

XOR and handwritten digits

The repository provides two complete entry points: a tiny nonlinear problem and a larger classification experiment.

Run XOR

From the project directory, with JDK 17 and Maven installed:

mvn compile
mvn exec:java

Main.java learns the four XOR rows: only inputs with different bits have target 1. It uses topology {2, 8, 1}, tanh hidden neurons, a sigmoid output, MSE, Adam at 0.01, and full batches of four for 10,000 epochs.

import org.example.deeplearning.activation.ActivationFunction;
import org.example.deeplearning.core.NeuralNetwork;
import org.example.deeplearning.loss.LossFunction;
import org.example.deeplearning.optim.Adam;
import org.example.deeplearning.training.Trainer;

// Inside a method:
double[][] x = {{0,0}, {0,1}, {1,0}, {1,1}};
double[][] y = {{0}, {1}, {1}, {0}};
NeuralNetwork net = new NeuralNetwork(
    new int[]{2, 8, 1},
    new ActivationFunction[]{ActivationFunction.linear(),
        ActivationFunction.tanh(), ActivationFunction.sigmoid()},
    LossFunction.meanSquaredError(), new Adam(0.01), 42L);
net.fit(new Trainer(10_000, 4, true, 42L), x, y);
System.out.println(net.predict(new double[]{0, 1})[0]);

A successful run should produce outputs near 0, 1, 1 and 0 respectively. Exact results can depend on configuration and environment. XOR cannot be represented by a single linear decision boundary; the hidden nonlinear layer provides the necessary flexibility.

Try regression

The new RegressionExample fits y = 2x + 1 with a linear output, Huber loss and RMSProp:

java -cp target/classes org.example.deeplearning.examples.RegressionExample

Run MNIST

mvn compile
java -cp target/classes org.example.deeplearning.examples.MNISTRunner --quick

The runner downloads MNIST on first use, loads 28 × 28 images, scales byte values to [0,1], and one-hot encodes digit labels. Quick mode limits training to at most 10,000 examples; loading still reads the dataset. The architecture is 784 → 128 → 64 → 10, with ReLU hidden layers, sigmoid outputs, MSE, Adam, batch size 256 and five epochs.

It predicts the index of the largest output and displays a confusion matrix whose rows are actual digits and columns are predictions. The ten sigmoids are independent and need not sum to one. A softmax plus categorical cross-entropy approach is common for mutually exclusive classes, but is not part of this starter library.

The MNIST command requires network access for the initial download and can take substantial time and memory. Check the console for progress.
