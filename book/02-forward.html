02 · Forward pass

From inputs to prediction

Each neuron combines the previous layer’s outputs with its own weights and bias, then applies an activation.

zi(l) = bi(l) + Σj wij(l)aj(l−1)     ai(l) = f(l)(zi(l))

Here z is the weighted sum, a is the output after activation, and wij connects previous neuron j to current neuron i. The inputs are the values of layer zero.

Work a tiny network by hand

Use one input, one hidden neuron, one output neuron, and sigmoid activations. Let x = 1, hidden weight w₁ = 0.5, hidden bias b₁ = 0, output weight w₂ = 0.8, output bias b₂ = −0.1, and target t = 1.

z₁ = 0.5 × 1 + 0 = 0.5
h  = sigmoid(0.5) ≈ 0.622459
z₂ = 0.8 × h − 0.1 ≈ 0.397967
p  = sigmoid(z₂) ≈ 0.598199

With one output, mean squared error is (p − t)² ≈ 0.161444. The next chapter uses these same values to compute gradients.

The Java loop

double sum = neuron.bias;
for (int j = 0; j < previous.neurons.length; j++) {
    sum += previous.neurons[j].value * neuron.weights[j];
}
neuron.value = activations[l].activate(sum);

That is the core of forwardPropagate. It checks the input size and finiteness, copies the inputs into layer zero, then traverses layers from left to right. It returns a fresh output array. predict simply delegates to this method.

Why keep outputs? Backpropagation needs the previous layer’s outputs for weight gradients. Here each neuron stores its latest activated value, and every supplied derivative can be computed from that value.
