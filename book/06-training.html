06 · Training

Turn gradients into learning

Training repeats prediction, gradient computation and parameter updates across examples. The optimizer decides how large a step to take.

Epochs and mini-batches

One epoch visits the training set once. fit creates an index order, optionally shuffles it with Fisher–Yates, divides it into batches, and passes each batch to trainBatch. The last batch may be smaller. Its gradients are divided by its actual size.

Trainer trainer = new Trainer(
    10_000,  // epochs
    4,       // examples per batch
    true,    // shuffle each epoch
    42L      // shuffle seed
);
network.fit(trainer, inputs, targets);

A fixed seed makes the initial random choices repeatable under the same runtime and call sequence. Separate seeds control network initialization and shuffling. An optimizer instance holds state; use a separate instance for each independently trained network.

SGD and momentum

v ← μv + g     θ ← θ − ηv

Here θ is a parameter, g its batch gradient, η the learning rate and μ the momentum. new SGD(rate) sets μ to zero. Momentum accumulates a running direction and can smooth oscillations. The implementation resets velocity if the parameter array length changes.

Adam

m ← β₁m + (1−β₁)g     v ← β₂v + (1−β₂)g²
m̂ = m/(1−β₁ᵗ)     v̂ = v/(1−β₂ᵗ)     θ ← θ − η m̂/(√v̂ + ε)

Adam tracks a moving average of gradients and squared gradients per parameter. Bias correction compensates for initialization at zero. Defaults are β₁ = 0.9, β₂ = 0.999 and ε = 10⁻⁸. Its timestep advances once per mini-batch update, not once per example.

RMSProp

new RMSProp(0.01) tracks an exponentially weighted average of squared gradients and divides each gradient by the square root of that average plus epsilon. Defaults are decay 0.9 and epsilon 10⁻⁸. Like Adam, each optimizer instance holds state and should belong to one network.

Diagnose learning

  • If loss becomes non-finite or jumps wildly, check input scaling and try a smaller learning rate.
  • If training loss hardly changes, inspect outputs, targets, activation saturation, gradient flow and learning rate.
  • If training improves but unseen examples do not, investigate overfitting and data leakage.

The sample MNIST runner prints test accuracy after every epoch. For actual model selection, reserve a separate validation set for decisions and leave the test set untouched until final evaluation.
