08 · Reference

Read, extend, experiment

Use the implementation as a readable laboratory. Its simplicity makes both its strengths and its limits easy to see.

Key entry points

MethodPurpose
predict(double[])Run one forward pass and return the output.
calculateLoss(double[][], double[][])Average per-example loss across a dataset.
trainBatch(double[][], double[][])Compute mean batch gradients and perform one optimizer update.
fit(Trainer, double[][], double[][])Shuffle and train for the configured number of epochs.

Additional components

MeanAbsoluteError and HuberLoss implement LossFunction; RMSProp implements Optimizer. WeightInitializer provides Xavier uniform and He normal strategies. ClassificationMetrics supplies argmax, accuracy and a confusion matrix.

Important boundaries

  • Dense feed-forward layers only: no convolutions, recurrence, dropout or automatic differentiation.
  • Activation derivatives are defined in terms of output values. A new activation whose derivative needs information lost in the output may require caching pre-activation values and changing the interface.
  • There is no softmax or categorical cross-entropy, model serialization, GPU support, or built-in validation split.
  • Neurons contain mutable per-pass state and optimizers contain update history. Avoid sharing a network concurrently without coordination and avoid sharing an optimizer across networks.
  • Dataset validation checks dimensions, and forward propagation checks finite inputs; target finiteness is not comprehensively validated.

Experiments

  1. Change the XOR hidden layer from 8 to 2 neurons. Compare several initialization seeds and final losses.
  2. Change the XOR loss to binary cross-entropy and examine convergence, remembering the implementation’s clipping behavior.
  3. Switch between SGD and Adam and compare learning curves at several learning rates.
  4. Add a validation split to the MNIST runner, then use the test set only after choosing your settings.
  5. Implement a gradient check for a small deterministic network and compare analytic and finite-difference gradients.

Glossary

Weight: strength of an incoming connection. Bias: adjustable offset. Activation: transformed neuron output. Gradient: local rate of loss change with respect to a parameter. Learning rate: scale of an update. Batch: examples contributing to one update. Epoch: one pass through the training examples.
