05 · Losses

Give learning a direction

A loss is a single number measuring how far a prediction is from its target. Its gradient tells backpropagation which changes would increase that number.

Mean squared error

L = (1/n) Σi(pi − ti)²     ∂L/∂pi = 2(pi − ti)/n

The library averages over output components. calculateLoss then averages these per-example values over the dataset. Squaring makes large errors contribute disproportionately. MSE is natural for many regression problems, and the supplied XOR and MNIST examples also use it.

LossFunction mse = LossFunction.meanSquaredError();
double value = mse.loss(new double[]{0.2, 0.8}, new double[]{0, 1});
// value = 0.04; gradient = [0.2, -0.2]

Binary cross-entropy

L = −(1/n) Σi[ti log(pi) + (1−ti) log(1−pi)]

∂L/∂pi = [−ti/pi + (1−ti)/(1−pi)]/n

For a target of 1, a confident prediction near 0 has a large penalty. This implementation expects targets in [0,1] in the loss calculation and uses the natural logarithm. Pair it with sigmoid outputs; this is binary cross-entropy applied independently to each output, not categorical cross-entropy.

To keep logarithms and divisions finite, the implementation clamps predictions to [10⁻¹², 1−10⁻¹²] in both loss and gradient. Outside that interval its returned gradient is evaluated at the clamped value; it is not the mathematical derivative of the clamped loss. At saturated values, this and floating-point rounding can affect learning. The gradient method itself does not validate target range; callers should supply valid targets.

More regression losses

new MeanAbsoluteError() averages absolute errors and chooses zero as the subgradient at zero. new HuberLoss(delta) uses ½d² when |d| ≤ delta and delta(|d| − ½delta) otherwise, averaged over outputs. Huber is quadratic near zero and linear for larger errors.

Loss is not accuracy

Accuracy counts correct class decisions; loss reflects how the predictions score against targets. A model can improve its loss without changing any argmax decisions. Examine both, and evaluate on data that was not used for training.
