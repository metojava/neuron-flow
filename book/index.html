A small network, understood deeply

A practical guide to neural networks through a compact Java implementation. Follow a number from input to prediction, then trace the error backwards to every weight.

Input features→Forward prediction→Loss error→Backward gradients→Update learning

What you will build an understanding of

The project in nfs implements a fully connected feed-forward network using ordinary Java arrays and loops. Its small size makes the mechanics visible: there is no automatic differentiation engine hiding the chain rule.

How to read this book

Start with the map if you are new to the code. The forward and backward chapters use the same tiny worked example. Each chapter contains equations, explanations, and Java snippets. You can open these pages directly from disk; no server or internet connection is required.

New to the notation? The backpropagation chapter explains derivatives and the ∂ symbol in plain language before introducing formulas.
