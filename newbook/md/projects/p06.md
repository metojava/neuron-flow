# Reading reviews with bag-of-words

*Text cannot be fed to a network as strings, so this project turns each movie review into a count vector over the 10,000 most frequent words — no embeddings, no sequences, no tokenizer library. It is the simplest honest approach to NLP, and it still reaches about 88% sentiment accuracy.*

## What the project does

Each review becomes a sparse vector: how many times each vocabulary word appeared, scaled to [0, 1]. The network sees only word counts, yet words like "masterpiece" and "dull" carry enough signal to separate positive from negative reviews.

"a slow dull film" → counts[vocab] = {a:1, slow:1, dull:1, film:1, …} → 10000-dim vector

## Building the vocabulary

```
Map<String, Integer> vocab = new HashMap<>();
int nextId = 0;

for (String review : rawTrain) {
    for (String word : review.toLowerCase().split("\\W+")) {
        if (word.isBlank()) continue;
        if (vocab.size() >= VOCAB_SIZE) break;
        vocab.putIfAbsent(word, nextId++);
    }
}

float[] vectorize(String review) {
    float[] v = new float[VOCAB_SIZE];
    for (String word : review.toLowerCase().split("\\W+")) {
        Integer id = vocab.get(word);
        if (id != null) v[id] += 1f;
    }
    // sublinear scaling: 1 + log(count), then cap at 1
    for (int i = 0; i < v.length; i++) {
        if (v[i] > 0) v[i] = (float) (Math.min(v[i], 1f + Math.log(v[i])) / 50f);
    }
    return v;
}
```

## The architecture

```
int[] topology = {10000, 128, 1};

ActivationFunction[] activations = {
    ActivationFunction.linear(),   // word-count vector
    ActivationFunction.relu(),     // learned word combinations
    ActivationFunction.sigmoid()   // P(positive)
};

NeuralNetwork net = new NeuralNetwork(
    topology, activations,
    LossFunction.binaryCrossEntropy(),
    new Adam(0.001f),
    42L,
    WeightInitializer.heNormal());

net.fit(new Trainer(10, 64, true, 42L), trainVectors, trainTargets);
```

> **Why 10,000 inputs and only 128 hidden?** The input layer is huge but shallow — it is just a lookup table of word counts. The compression to 128 units forces the network to learn which *combinations* of words matter, which is exactly the useful representation.

The two classes are balanced (12,500 each), so accuracy and the class metrics agree. Errors concentrate in mixed reviews — "great visuals, terrible story" contains strong words on both sides, and bag-of-words throws away the order that would resolve it.

## What you learn from this project

- **Text → numbers** — tokenization, vocabulary construction, and count vectors, all in a few lines of Java with no NLP library.
- **Sparse high-dimensional input** — 10,000 inputs, most of them zero, is normal; the network handles it like any other layer.
- **Information loss** — bag-of-words discards word order, which is precisely the limitation that recurrent and transformer models later address.
- **Generalization with regularization** — adding `Dropout` (rate 0.3) on the hidden layer narrows the train/test gap by 2–3 points.
