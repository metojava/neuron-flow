# Two networks, one liar and one detective

*A GAN trains two networks against each other: the generator invents images from random noise, and the discriminator decides which images are real. Neither ever sees a label — the generator learns purely from the discriminator's verdict, and the result is a model that creates new Fashion-MNIST-style pictures.*

## What the project does

The generator maps a 100-dim random vector to a 784-pixel image; the discriminator maps 784 pixels to one probability: real or fake. They are trained in alternation, so as the detective gets sharper the forger must improve — a moving target that is the whole difficulty of GAN training.

**Generator** (noise → 784) → **Discriminator** (real or fake?) → **Reward** (BCE both sides) → **Repeat** (thousands ×)

## The two architectures

```
// generator: 100 random numbers -> one fake image
NeuralNetwork generator = new NeuralNetwork(
    new int[] {100, 256, 784},
    new ActivationFunction[] {
        ActivationFunction.leakyRelu(0.2f),
        ActivationFunction.relu(),
        ActivationFunction.sigmoid()     // pixels in [0, 1]
    },
    LossFunction.binaryCrossEntropy(),
    new Adam(0.0002f), 42L, WeightInitializer.heNormal());

// discriminator: one image -> P(real)
NeuralNetwork discriminator = new NeuralNetwork(
    new int[] {784, 256, 1},
    new ActivationFunction[] {
        ActivationFunction.leakyRelu(0.2f),
        ActivationFunction.relu(),
        ActivationFunction.sigmoid()
    },
    LossFunction.binaryCrossEntropy(),
    new Adam(0.0002f), 43L, WeightInitializer.heNormal());
```

> **Same loss, opposite goals.** The discriminator minimizes BCE with targets 1 for real images and 0 for fakes. The generator also minimizes BCE, but with target 1 for images it just produced — it wins when the discriminator answers "real".

## The adversarial training step

```
Random rng = new Random(42L);

for (int step = 0; step < 5000; step++) {
    // 1. train the discriminator on one real and one fake batch
    float[][] real = realBatch(images, 32, rng);
    float[][] fake = fakeBatch(generator, 32, rng);

    discriminator.fit(new Trainer(1, 32, false, step),
        concat(real, fake),
        concat(zeros(32), ones(32)));

    // 2. train the generator: fool the (frozen-judgement) discriminator
    float[][] noise = gaussian(32, 100, rng);
    float[][] produced = predictAll(generator, noise);

    generator.fit(new Trainer(1, 32, false, step),
        noise, ones(32));   // label them all "real"

    if (step % 500 == 0) {
        System.out.printf("step %4d  D loss %.4f  G loss %.4f%n",
            step, discriminator.calculateLoss(dX, dY),
                  generator.calculateLoss(noise, ones(32)));
    }
}
```

## Expected training dynamics

```
step    0  D loss 0.6931  G loss 0.6944   (both guessing)
step  500  D loss 0.4812  G loss 0.9210   (D getting better)
step 1500  D loss 0.3904  G loss 1.4025   (G struggling)
step 3000  D loss 0.5518  G loss 0.8106   (G improving)
step 5000  D loss 0.6127  G loss 0.6844   (near equilibrium)
```

A healthy GAN ends near D loss ≈ 0.69 — the discriminator is barely better than a coin flip because the fakes are convincing. Early on, D loss near 0 means it wins too easily and the generator receives no useful gradient; that is the signal to slow the discriminator or speed up the generator.

## What you learn from this project

- **Adversarial training** — two optimizers, two losses, one moving target; the concept behind modern image generation.
- **Latent-space sampling** — random vectors become structured images, connecting back to the autoencoder's bottleneck in project 7.
- **Diagnosing instability** — reading the D/G loss pair to tell convergence from mode collapse from a stalled discriminator.
- **Pulling it all together** — activations, losses, optimizers, batching, seeds and model persistence, from all eleven previous projects, in one system.
