# The book's main example, end to end

*This is the project the rest of the book keeps coming back to: 70,000 clothing images, a 784-128-10 multilayer perceptron, ReLU hidden units, softmax cross-entropy, and Adam. It downloads its own data, trains in seconds, and lands around 84% test accuracy — respectable for a plain MLP with no convolution.*

## What the project does

It classifies 28×28 grayscale clothing photos into ten categories: T-shirt, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot. The interesting part is that the model never sees a single example of "what a shirt looks like" — it only sees 784 numbers and a label, and still learns shape and texture differences.

**Download** (4 .gz files) → **Normalize** (pixels to [0,1]) → **Train** (Adam, 10 epochs) → **Report** (confusion matrix)

## The architecture

```
int[] topology = {784, 128, 10};

ActivationFunction[] activations = {
    ActivationFunction.linear(),   // raw pixels pass through
    ActivationFunction.relu(),     // 128 feature detectors
    ActivationFunction.linear()    // 10 class scores (logits)
};

NeuralNetwork net = new NeuralNetwork(
    topology, activations,
    LossFunction.softmaxCrossEntropy(),
    new Adam(0.001f),
    123L,
    WeightInitializer.heNormal());
```

> **Why He + ReLU?** ReLU kills half its inputs on every layer, so its weights need a larger initial spread than sigmoid nets. `WeightInitializer.heNormal()` scales by `sqrt(2 / fanIn)`, keeping the variance stable as signals pass through.

## Key setup code

```
Path dataDir = FashionMNISTDownloader.ensureDownloaded();
FashionMNISTLoader.Dataset data =
    FashionMNISTLoader.load(dataDir);

float[][] trainX     = data.trainImages();          // 60000 × 784
float[][] trainY     = data.trainTargetsOneHot();   // 60000 × 10
float[][] testX      = data.testImages();           // 10000 × 784
int[]     testLabels = data.testLabels();           // 10000

net.fit(new Trainer(10, 32, true, 123L), trainX, trainY);
```

```
int[] predicted = new int[testX.length];
for (int i = 0; i < testX.length; i++) {
    predicted[i] = ClassificationMetrics.argmax(net.predict(testX[i]));
}

int[][] confusion = ClassificationMetrics
    .confusionMatrix(predicted, testLabels,
                     FashionMNISTLoader.NUM_CLASSES);

System.out.printf("Test accuracy: %.2f%%%n",
    ClassificationMetrics.accuracy(predicted, testLabels) * 100);

ClassificationMetrics.printReport(System.out, confusion,
    FashionMNISTLoader.CLASS_NAMES);

net.saveModel(Path.of("fashion-mnist.model"));
```

## Expected results

```
epoch  1  loss 0.6841  accuracy 74.2%
epoch  2  loss 0.4612  accuracy 82.1%
epoch  4  loss 0.3698  accuracy 86.4%
epoch  7  loss 0.3120  accuracy 88.9%
epoch 10  loss 0.2804  accuracy 90.1%

Test accuracy: 84.07% (8407/10000)
```

The training accuracy (~90%) sits above test accuracy (~84%) — the usual small generalization gap. Loss falls smoothly, and the confusion matrix shows the classic confusions: Coat↔Pullover, Shirt↔T-shirt/top. Trouser and Ankle boot are near 96% recall because their silhouettes are unique.

## What you learn from this project

- **The complete supervised loop** — download, load, one-hot, train, evaluate, print, save. This is the skeleton of every classification project that follows.
- **Adam vs SGD** — with the same topology, SGD(0.1) needs careful tuning and lands ~10 points lower; Adam at 0.001 just works.
- **Confidence vs correctness** — high softmax scores do not guarantee the right class; the confusion matrix measures what confidence alone cannot.
- **Model persistence** — `saveModel` writes weights to disk; `NeuralNetwork.loadModel(...)` rebuilds the network without retraining.
