# Multi-armed bandit, epsilon-greedy, and reward tracking

*There are no labels in this project — only rewards. A four-armed bandit pays out according to hidden probabilities, and the network must learn which arm to pull by trial and error. It is the smallest possible reinforcement-learning problem, and it shows the explore-versus-exploit trade-off in one clean curve.*

## What the project does

Each step, the agent sees a 4-dim context, picks one of four arms, and receives a reward in [0, 1]. The network predicts a value for every arm; ε of the time it ignores those predictions and tries a random arm. Over 2,000 steps the average reward climbs toward the best arm's payoff.

a = random < ε ? random arm : argmax Q(s, a) → reward r → move Q toward r

## The architecture

```
int ARMS = 4;

int[] topology = {4, 16, ARMS};

ActivationFunction[] activations = {
    ActivationFunction.linear(),   // context: current state features
    ActivationFunction.relu(),
    ActivationFunction.linear()    // one Q-value per arm
};

NeuralNetwork qNet = new NeuralNetwork(
    topology, activations,
    LossFunction.meanSquaredError(),
    new SGD(0.01f),
    42L,
    WeightInitializer.xavierUniform());
```

## ε-greedy selection and the learning step

```
float epsilon = 0.10f;
Random rng = new Random(42L);
float totalReward = 0f;

for (int step = 0; step < 2000; step++) {
    float[] state = contextFor(step);          // 4-dim context
    float[] q = qNet.predict(state);

    int arm;
    if (rng.nextFloat() < epsilon) {
        arm = rng.nextInt(ARMS);               // explore
    } else {
        arm = ClassificationMetrics.argmax(q); // exploit
    }

    float reward = bandit.pull(arm);            // hidden payoff
    totalReward += reward;

    // supervise the chosen arm's output toward the reward
    float[] target = q.clone();
    target[arm] = reward;
    qNet.fit(new Trainer(1, 1, false, step), 
        new float[][] {state}, new float[][] {target});

    if (step % 200 == 0) {
        System.out.printf("step %4d  avg reward %.3f  eps %.2f%n",
            step, totalReward / (step + 1), epsilon);
    }
    epsilon = Math.max(0.01f, epsilon * 0.999f);   // decay
}
```

> **Why MSE here?** The target vector is the current Q-values with only the chosen arm corrected toward its observed reward — a one-step temporal-difference update with squared error. Predictions for arms that were *not* pulled stay unchanged because their targets equal their current outputs.

## Expected output

```
step    0  avg reward 0.412  eps 0.10
step  200  avg reward 0.507  eps 0.10
step  600  avg reward 0.594  eps 0.09
step 1200  avg reward 0.641  eps 0.08
step 1999  avg reward 0.668  eps 0.07

best arm estimated Q: [0.19 0.68 0.31 0.44]
true arm payoffs:     [0.20 0.70 0.30 0.45]
```

The average reward rises quickly as the network identifies arm 1, then flattens — the remaining gap comes from the ε exploration that is deliberately kept on. Set ε to 0 and you exploit perfectly but never discover that arm 1 was best in the first place.

## What you learn from this project

- **Learning from rewards** — no dataset, no labels; the environment supplies the training signal one action at a time.
- **Exploration vs exploitation** — ε controls the trade-off, and the decay schedule shows why you explore early and exploit later.
- **Turn RL into supervised updates** — a target vector built from the observed reward lets you reuse `fit` unchanged.
- **Tracking progress** — a running average of reward is the metric that matters; instantaneous reward is far too noisy to read.
