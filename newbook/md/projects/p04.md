# Two classes, thirty features, and the cost of a wrong answer

*This project trains a binary classifier on the Wisconsin breast-cancer dataset: 569 samples, 30 real-valued features measured from cell nuclei, and one label (malignant or benign). It is the first project where accuracy alone is not enough — missing a malignant case matters much more than a false alarm, so we report precision and recall.*

## What the project does

Given 30 numbers per patient (radius, texture, perimeter, area, smoothness, and so on), the network outputs a single value in (0, 1): the estimated probability of malignancy. Thresholding at 0.5 turns that probability into a decision, and the confusion matrix turns decisions into precision and recall.

P(y = 1 | x) = σ(z) ∈ (0, 1) → predict malignant if P ≥ 0.5

## The architecture

```
int[] topology = {30, 16, 8, 1};

ActivationFunction[] activations = {
    ActivationFunction.linear(),   // 30 normalized features
    ActivationFunction.relu(),     // hidden layer 1
    ActivationFunction.relu(),     // hidden layer 2
    ActivationFunction.sigmoid()   // single probability
};

NeuralNetwork net = new NeuralNetwork(
    topology, activations,
    LossFunction.binaryCrossEntropy(),
    new Adam(0.001f),
    42L,
    WeightInitializer.heNormal());
```

> **Why BCE instead of MSE?** With a sigmoid output, binary cross-entropy gives a gradient proportional to `ŷ − y` with no saturation term — the network learns fast even when it is confidently wrong. MSE on a sigmoid has a gradient multiplied by `σ'(z)`, which shrinks near 0 and 1 and stalls training.

## Predictions, precision and recall

```
int[] predicted = new int[testX.length];

for (int i = 0; i < testX.length; i++) {
    float p = net.predict(testX[i])[0];
    predicted[i] = p >= 0.5f ? 1 : 0;
}

int[][] confusion = ClassificationMetrics
```

## Expected output

```
Accuracy:  96.49% (110/114)
Precision: 0.957
Recall:    0.979
F1:        0.968

Confusion matrix (rows = actual, cols = predicted):
              benign  malignant
benign           69       2
malignant         1      42
```

Two false positives (benign flagged as malignant) are cheap — they lead to a second test. One false negative would be dangerous, so we check the malignant row: 42 of 43 caught, recall 0.979. Lowering the threshold to 0.35 would raise recall further at the cost of more false alarms.

## What you learn from this project

- **Binary output design** — one sigmoid neuron, one BCE loss, one threshold: the complete recipe for two-class problems.
- **Metric selection** — accuracy, precision, recall and F1 answer different questions; the right metric depends on which mistake is expensive.
- **Class imbalance awareness** — 357 benign vs 212 malignant: accuracy can look fine while the minority class is ignored, which is why per-class numbers matter.
- **Feature scaling** — mixed units require normalization; unscaled input makes training slower and results unstable.
