20.1 Complete GPT model

GPTModel provides the decoder backbone with learned positional embeddings (not RoPE by default). Construct from GPTConfig or individual parameters.

GPTConfig config = GPTConfig.gpt2Small(); // 12 layers, 768 hidden, 12 heads
config.hiddenSize = 768;
config.numHiddenLayers = 12;
config.numAttentionHeads = 12;
config.intermediateSize = 3072;
config.vocabSize = 50257;
config.maxPositionEmbeddings = 1024;

GPTModel gpt = new GPTModel(config, 42L);

// Forward pass with optional KV cache
Tensor hidden = gpt.forward(inputIds, batchSize, seqLen, pastK, pastV, pastLen);
Tensor logits = lmHead.forward(hidden);  // {B, T, V}

20.2 Generation features

GPTLMHeadModel.generate() supports a complete generation pipeline:

  • KV cache: Efficient autoregressive generation without recomputing the prefix at each step.
  • Temperature sampling: temperature=0 for greedy, >0 for sampling.
  • Top-K filtering: Keep only top-K logits (e.g., topK=40).
  • Top-P (nucleus) sampling: Keep smallest set of tokens with cumulative probability ≥ topP (e.g., topP=0.9).
  • Repetition penalty: Penalizes repeated tokens (from CTRL paper). penalty=1.0 disables, >1.0 penalizes.
  • Stop sequences: Stop generation when any token in stopTokenIds is generated (e.g., EOS token).
  • Temperature + top-p + top-k: All three can be combined; top-K applied first, then top-P, then temperature scaling.

20.3 Beam Search Decoding

BeamSearchDecoder implements beam search with length penalty.

BeamSearchDecoder decoder = new BeamSearchDecoder(gptModel, 5); // beam size = 5
int[] generated = decoder.generate(promptIds, 50, 0.6f); // maxNewTokens=50, lengthPenalty=0.6

Features:

  • Maintains top-beamSize candidates at each step.
  • Length penalty: score / length^alpha (default alpha=0.6).
  • KV cache shared across beams for efficiency.
  • Early stopping when all beams generate EOS token.

20.4 Configuration

Use GPTConfig for all parameters. Predefined configurations available:

GPTConfig config = GPTConfig.gpt2Small();   // 124M params: 12 layers, 768 hidden, 12 heads
GPTConfig config = GPTConfig.gpt2Medium();  // 350M params: 24 layers, 1024 hidden, 16 heads
GPTConfig config = GPTConfig.gpt2Large();   // 774M params: 36 layers, 1280 hidden, 20 heads
GPTConfig config = GPTConfig.gpt2XLarge();  // 1.5B params: 48 layers, 1600 hidden, 25 heads

// Custom config
GPTConfig config = GPTConfig.of(50257, 768, 12, 12, 3072, 1024);

20.5 Loading Pretrained GPT-2 Weights

GPTConfig config = GPTConfig.gpt2Small();
GPTLMHeadModel model = new GPTLMHeadModel(config, 42L);

HFWeightLoader.loadWeights(model, Paths.get("pytorch_model.safetensors"), "gpt2");
