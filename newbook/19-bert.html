19 · BERT

Encoder-only models: complete BERT implementation

NeuronFlow now provides a complete BERT implementation with BertModel, BertForMaskedLM, BertForNextSentencePrediction, BertForSequenceClassification, BertForPreTraining, MLMMasker, NSPHead, and PoolingLayer. All components are built on the transformers autograd engine.

19.1 Status: Complete implementation

Fully implemented. All core BERT components are available: token embeddings, position embeddings, segment embeddings, encoder blocks, encoder stack, attention mask for padding, MLM head, NSP head, [CLS] pooling, pretraining objectives, MLM masker, and pretrained weight loading via safetensors/HF weight loader.

19.2 Complete BERT model

BertModel combines the encoder backbone with a pooling layer for [CLS] token extraction. Construct from BertConfig or individual parameters.

BertConfig config = BertConfig.bertBaseUncased();
BertModel bert = new BertModel(config, 42L);

// Forward pass with segment ids and attention mask
int[] inputIds = tokenizer.encode("Hello world");
int[] segmentIds = new int[inputIds.length]; // single segment
int[] attentionMask = new int[inputIds.length];
Arrays.fill(attentionMask, 1);

BertModel.BertOutput output = bert.forward(inputIds, segmentIds, attentionMask);
Tensor lastHiddenState = output.lastHiddenState;  // [B, T, D]
Tensor pooledOutput = output.pooledOutput;         // [B, D] - [CLS] representation

19.3 Masked Language Modeling

BertForMaskedLM provides the complete MLM pipeline: masking, forward pass, and loss computation.BertForMaskedLM mlm = new BertForMaskedLM(config, 42L); // Prepare masked input (use MLMMasker for BERT-style masking) int[] inputIds = tokenizer.encode("The [MASK] is blue"); MLMMasker masker = new MLMMasker(config.maskTokenId, config.vocabSize, 42L); MLMMasker.MaskedResult masked = masker.mask(inputIds); // masked.inputIds - input with [MASK] replacements // masked.labels - target ids (-100 for non-masked positions) BertForMaskedLM.MaskedLMOutput output = mlm.forward( masked.inputIds, null, null, masked.labels); Tensor logits = output.logits; // [B, T, V] or [M, V] for masked positions Tensor loss = output.loss; // MLM cross-entropy loss

MLMMasker implements the standard BERT masking strategy: 15% of tokens selected, then 80% replaced with [MASK], 10% random token, 10% unchanged. Special tokens (CLS, SEP, PAD, MASK) are never masked.

19.4 Next Sentence Prediction

BertForNextSentencePrediction adds the NSP head on top of the pooled [CLS] output.

BertForNextSentencePrediction nsp = new BertForNextSentencePrediction(config, 42L);

// segmentIds: 0 for sentence A, 1 for sentence B
// nspLabels: 0 = isNext, 1 = notNext
BertForNextSentencePrediction.NSPOutput output = nsp.forward(
    inputIds, segmentIds, attentionMask, nspLabels);

Tensor logits = output.logits;  // [B, 2] (isNext, notNext)
Tensor loss = output.loss;      // NSP cross-entropy loss

19.5 Sequence Classification

BertForSequenceClassification adds a classification head on the pooled [CLS] output.

BertForSequenceClassification classifier = new BertForSequenceClassification(config, numLabels, 42L);

BertForSequenceClassification.SequenceClassificationOutput output = 
    classifier.forward(inputIds, segmentIds, attentionMask, labels);

Tensor logits = output.logits;  // [B, numLabels]
Tensor loss = output.loss;      // cross-entropy loss (if labels provided)

19.6 Complete Pretraining: MLM + NSP

BertForPreTraining combines both objectives for full BERT pretraining.

BertForPreTraining pretraining = new BertForPreTraining(config, 42L);

BertForPreTraining.PreTrainingOutput output = pretraining.forward(
    inputIds, segmentIds, attentionMask, mlmLabels, nspLabels);

Tensor mlmLogits = output.mlmLogits;   // [B, T, V]
Tensor nspLogits = output.nspLogits;   // [B, 2]
Tensor mlmLoss = output.mlmLoss;
Tensor nspLoss = output.nspLoss;
Tensor totalLoss = output.loss;        // mlmLoss + nspLoss

19.7 MLM Masking

MLMMasker implements the standard BERT masking strategy:

MLMMasker masker = new MLMMasker(config.maskTokenId, config.vocabSize, 42L);
MLMMasker.MaskedResult masked = masker.mask(inputIds);

// masked.inputIds  - input with [MASK]/random/unchanged replacements
// masked.labels    - target ids (original token id) or -100 for non-masked
// masked.maskCount - number of masked positions

Strategy: 15% of tokens selected for masking. Of those: 80% → [MASK], 10% random token, 10% unchanged. Special tokens (CLS=101, SEP=102, PAD=0, MASK=103) are never masked.

19.8 Configuration

Use BertConfig for all parameters. Predefined configurations available:

BertConfig config = BertConfig.bertBaseUncased();     // 12 layers, 768 hidden, 12 heads
BertConfig config = BertConfig.bertLargeUncased();   // 24 layers, 1024 hidden, 16 heads
BertConfig config = BertConfig.bertTiny();           // 2 layers, 128 hidden, 2 heads
BertConfig config = BertConfig.bertMini();           // 4 layers, 256 hidden, 4 heads
BertConfig config = BertConfig.bertSmall();          // 4 layers, 512 hidden, 8 heads
BertConfig config = BertConfig.bertMedium();         // 8 layers, 512 hidden, 8 heads

// Custom config
BertConfig config = BertConfig.of(30522, 768, 12, 12, 3072);

19.9 Loading Pretrained Weights

Use HFWeightLoader to load Hugging Face safetensors weights with automatic key mapping:

BertConfig config = BertConfig.bertBaseUncased();
BertModel model = new BertModel(config, 42L);

HFWeightLoader.loadWeights(model, Paths.get("pytorch_model.safetensors"), "bert");

The loader maps Hugging Face state_dict keys (e.g., encoder.layer.0.attention.self.query.weight) to NeuronFlow parameter names automatically. Supports BERT-base, BERT-large, and custom configurations.19.10 What is missing

The following BERT components are not yet implemented:

  • WordPiece tokenizer: Current Tokenizer is BPE (tiktoken-style), not WordPiece. For exact BERT compatibility, a WordPiece tokenizer is needed.
  • Gradient checkpointing: No activation recomputation for memory-efficient training.
  • Mixed precision pretraining: FP16 training with dynamic loss scaling works via MixedPrecisionContext but not extensively tested on full BERT.
  • Gradient checkpointing / activation recomputation for memory-efficient training of large models.
  • Full HF model zoo compatibility: Weight loader covers BERT-base/large but not all variants (RoBERTa, DeBERTa, etc.).
