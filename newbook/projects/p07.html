Project 7 · Image autoencoder

Squeeze 784 numbers into 32 — then rebuild them

An autoencoder is trained with no labels at all: the input image is also the target. The network must compress each image into 32 values and then reconstruct all 784 pixels from that bottleneck, which forces the 32 numbers to encode only what really matters about the data.

What the project does

784 pixels in, 32 numbers in the middle, 784 pixels out. The interesting part is the middle layer: those 32 values are a learned latent representation, and you can visualize them to see the network group similar images without ever being told the class labels.

Encode 784 → 128 → 32→ Bottleneck 32 values→ Decode 32 → 128 → 784→ Compare input vs output

The architecture

int[] topology = {784, 128, 32, 128, 784};

ActivationFunction[] activations = {
    ActivationFunction.linear(),  // pixels in [0, 1]
    ActivationFunction.relu(),    // encoder
    ActivationFunction.tanh(),    // latent: signed, centered at 0
    ActivationFunction.relu(),    // decoder
    ActivationFunction.sigmoid()  // pixels out in [0, 1]
};

NeuralNetwork net = new NeuralNetwork(
    topology, activations,
    LossFunction.meanSquaredError(),
    new Adam(0.001f),
    42L,
    WeightInitializer.heNormal());
Same shape in and out — same loss. MSE compares the reconstruction pixel by pixel with the original. Sigmoid on the final layer keeps outputs in [0, 1] so they are directly comparable to the input pixels.

Reading the latent space

// the bottleneck is the output of layer index 2
private static float[] encode(NeuralNetwork net, float[] image) {
    net.forwardPropagate(image);          // run the full pass
    Layer hidden = /* layer 2 of the network */;
    float[] z = new float[32];
    for (int i = 0; i < z.length; i++) {
        z[i] = hidden.neurons[i].value;
    }
    return z;
}

// project 32 dims onto two axes for a scatter plot
for (int i = 0; i < testImages.length; i++) {

}

What you learn from this project

  • Unsupervised learning — a training signal can come from the data itself, not from human labels.
  • Bottlenecks and compression — forcing information through a narrow layer is what makes a representation useful; widen it to 256 and reconstruction improves but structure disappears.
  • Symmetric architectures — encoder and decoder mirror each other, a pattern you will see again in project 12's generator.
  • Inspecting hidden layers — reading neuron.value after a forward pass gives you the network's internal features.
