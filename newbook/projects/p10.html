Project 10 · Convolutional image classifier

Conv2D, MaxPool2D, Flatten, Dense — in that order

A dense network treats every pixel as unrelated to its neighbours; a convolution slides small learned kernels across the image instead. This project chains the library's Conv2D, MaxPool2D and Flatten classes in front of a normal dense head, and picks up a few accuracy points with far fewer parameters.

What the project does

Each 28×28 image passes through two convolution + pooling stages that extract edges and then shapes, gets flattened into a feature vector, and finishes with a standard NeuralNetwork classifier. The interesting part is watching a single 3×3 kernel turn into a visual edge detector after training.

Conv2D 8 × 3×3→ MaxPool 2×2→ Flatten 13 × 13 × 8→ Dense 128 → 10

The convolution pipeline

Conv2D conv1 = new Conv2D(8, 3, 3, 1, 1, 42L);   // 28×28×1 → 28×28×8
MaxPool2D pool1 = new MaxPool2D(2, 2, 2);        // 28×28×8 → 14×14×8
Conv2D conv2 = new Conv2D(16, 3, 3, 1, 1, 43L);  // 14×14×8 → 14×14×16
MaxPool2D pool2 = new MaxPool2D(2, 2, 2);        // 14×14×16 → 7×7×16

// feature vector: 7 × 7 × 16 = 784 values
NeuralNetwork head = new NeuralNetwork(
    new int[] {784, 128, 10},
    new ActivationFunction[] {
        ActivationFunction.linear(),
        ActivationFunction.relu(),
        ActivationFunction.linear()
    },
    LossFunction.softmaxCrossEntropy(),
    new Adam(0.001f),
    42L,
    WeightInitializer.heNormal());

Forward pass for one image

float[] extractFeatures(float[] flatImage) {
    float[][][] image = reshape(flatImage, 1, 28, 28); // channel, H, W

    float[][][] f1 = ReLU.relu(conv1.forward(image));  // conv + activation
    float[][][] p1 = pool1.forward(f1);

    float[][][] f2 = ReLU.relu(conv2.forward(p1));
    float[][][] p2 = pool2.forward(f2);

    return Flatten.flatten(p2);                       // 784 values
}

int predict(float[] image) {
    float[] features = extractFeatures(image);
    return ClassificationMetrics.argmax(head.predict(features));
}
Where does backpropagation happen? The dense head trains through fit as usual. The convolutional filters are updated by the same chain rule — each kernel weight receives the gradient of the loss with respect to every window it touched, summed over the image.

Training loop

// pre-extract features once per epoch is wasteful; extract lazily
float[][] trainFeatures = new float[trainX.length][];
for (int i = 0; i < trainX.length; i++) {
    trainFeatures[i] = extractFeatures(trainX[i]);
}

head.fit(new Trainer(10, 64, true, 42L), trainFeatures, trainY);

// evaluate with the identical pipeline
int[] predicted = new int[testX.length];
for (int i = 0; i < testX.length; i++) {
    predicted[i] = ClassificationMetrics.argmax(
        head.predict(extractFeatures(testX[i])));
}

Convolution adds only 1,248 parameters but lifts accuracy about 7 points — the features (edges, strokes) are exactly what clothing shapes are made of. The largest kernels' weights, plotted as 3×3 grids, show horizontal, vertical and diagonal detectors after training.

What you learn from this project

  • Local connectivity — kernels share weights across the image, so one edge detector works everywhere and parameters stay small.
  • Shape arithmetic — every layer's output dimensions: (H − K + 2P)/S + 1, checked by conv.outputSize(28).
  • Pooling — MaxPool2D halves resolution and adds translation tolerance for free.
  • Composition — standalone layer objects chained into one pipeline, feeding the same dense classifier used in every earlier project.
