Encoder and decoder blocks built on autograd

The transformers package assembles attention, layer normalisation and feed-forward layers into encoder (BERT-style) and decoder (GPT-style) stacks. Every parameter is an autograd.Tensor, so gradients come from the engine in chapter 17.

18.1 Two transformer implementations

NeuronFlow contains two attention implementations, and they serve different stacks:

PackageNumeric typeStyleIntended use
layersdoubleExplicit forward/backward inside NeuralNetworkAttention as a layer in the dense network and CNN demos.
transformersfloatComposable objects returning TensorEncoder/decoder language models on the autograd engine.

This chapter covers the second. The classes are Embedding, Linear, LayerNorm, FeedForward, MultiHeadAttention, TransformerBlock, TransformerEncoder, TransformerDecoder, PositionalEmbedding, and supporting classes.

18.2 Shapes and conventions

SymbolMeaning
BBatch size (number of sequences).
TSequence length (tokens per sequence).
DModel width, dModel.
HNumber of attention heads; D must be divisible by H.
dHHead width, D / H.
VVocabulary size.
FFeed-forward hidden width, usually 4D.

Token ids are passed as a flat int[] of length B*T in row-major order. Hidden states are always {B,T,D}. Padding masks are supported via boolean arrays boolean[B][T] where true marks padding positions.

18.3 Building blocks

Embedding

A trainable lookup table of shape {V,D}, initialised from N(0, 0.02²). forward(ids, B, T) returns {B,T,D}; the backward pass scatters gradients back into the rows that were used.

Embedding embedding = new Embedding(vocabSize, dModel, seed);
Tensor x = embedding.forward(ids, batchSize, seqLen);

Linear

An affine projection of the last dimension: out = x @ W + b. Weights use He-normal initialisation N(0, 2/inFeatures); the bias starts at zero. Leading dimensions are flattened and restored, so the layer works on {B,T,in} as well as {N,in}. Supports weight tying for LM heads via tieWeights() and shared-weight constructor.

Linear projection = new Linear(dModel, vocabulary, seed);
Tensor logits = projection.forward(hiddenStates);   // {B,T,vocab}

LayerNorm

Normalises the last dimension with learnable gamma (initialised to 1) and beta (initialised to 0):

y = γ · (x - μ) / √(σ² + ε) + β     ε = 1e-5

FeedForward

Two linear layers with GELU in between: Linear(D,F) → GELU → Linear(F,D). It is applied independently at every position.

FeedForward ffn = new FeedForward(dModel, 4 * dModel, seed);

MultiHeadAttention

Self-attention with four projections: query, key, value and output. The input {B,T,D} is split into H heads of width dH, then

Attention(Q,K,V) = softmax(QKT / √dH) V

forward(x, true) adds a causal mask, so position t can only attend to positions ≤ t; forward(x) and forward(x, false) are bidirectional. The mask is a {T,T} tensor with -1e9 above the diagonal, broadcast over batch and heads.

Optional features:

  • RoPE (Rotary Positional Embeddings): Enable with useRoPE=true in constructor; precomputes cos/sin tables up to maxSeqLen.
  • Key padding mask: Pass boolean[][] keyPaddingMask to forward; true masks padding positions.
  • Dropout: Attention weight dropout and output projection dropout configurable via constructor.
  • KV cache: Pass pastK, pastV, pastLen to forward for autoregressive generation; returns updated K/V tensors.

TransformerBlock

Pre-normalised residual block with residual dropout:

h = x + Dropout(Attention(LayerNorm(x)))     y = h + Dropout(FeedForward(LayerNorm(h)))

The boolean useCausal selects decoder-style or encoder-style attention. Supports KV cache and key padding mask.

PositionalEmbedding

Combines token embeddings, learned positional embeddings, and optional segment embeddings (for BERT).

PositionalEmbedding posEmb = new PositionalEmbedding(vocabSize, dModel, maxSeqLen, typeVocabSize, useSegments, seed);
Tensor x = posEmb.forward(tokenIds, segmentIds, B, T);  // {B,T,D}

Can also accept pre-computed token embeddings via forward(tokenEmbs, segmentIds, B, T).

TransformerBlock

Pre-normalised residual block with residual dropout:

h = x + Dropout(Attention(LayerNorm(x)))     y = h + Dropout(FeedForward(LayerNorm(h)))

The boolean useCausal selects decoder-style or encoder-style attention. Supports KV cache and key padding mask.

Encoder and decoder stacks

TransformerEncoder and TransformerDecoder wrap an embedding, a list of numLayers blocks and a final layer norm. The encoder passes false to every block; the decoder passes true. Both expose parameters(), which concatenates every trainable tensor in the stack.

TransformerEncoder encoder = new TransformerEncoder(
        vocabSize, dModel, numHeads, numLayers, ffnHidden, seed);

TransformerDecoder decoder = new TransformerDecoder(
        vocabSize, dModel, numHeads, numLayers, ffnHidden, seed);

// With configs:
TransformerEncoder encoder = new TransformerEncoder(BertConfig.bertBaseUncased(), 42L);
TransformerDecoder decoder = new TransformerDecoder(GPTConfig.gpt2Small(), 42L);

// Forward with padding mask:
Tensor states = encoder.forward(ids, segmentIds, B, T, keyPaddingMask);
Tensor states = decoder.forward(ids, B, T, pastK, pastV, pastLen, keyPaddingMask);
List parameters = decoder.parameters();

18.4 Parameter count

For one block, attention has 4·(D² + D) parameters (four projections with biases), and the feed-forward has 2·(D·F) + D + F. Add 4·D for the two layer norms. The stack adds V·D for the embedding plus 2·D for the final norm. For D=128, H=4, F=512, L=4, V=1000 that is roughly 1.4 million parameters.

18.5 A decoder language-model step

The stack returns hidden states, not logits. Add a language-model head and shift the targets so position t predicts token t+1:

import autograd.Ops;
import autograd.Tensor;
import transformers.Linear;
import transformers.TransformerDecoder;

import java.util.List;

int vocab = 256;
int dModel = 32;
int heads = 4;
int layers = 2;
int ffn = 128;
int batch = 4;
int seqLen = 16;

TransformerDecoder decoder = new TransformerDecoder(
        vocab, dModel, heads, layers, ffn, 42L);
Linear lmHead = new Linear(dModel, vocab, 99L);
List parameters = new java.util.ArrayList<>(decoder.parameters());
parameters.addAll(lmHead.parameters());

int[] tokens = new int[batch * seqLen];
// ... fill tokens with ids in [0, vocab) ...
int[] nextTokens = new int[batch * seqLen];
// ... nextTokens[i] = tokens[i + 1] inside each sequence ...

Tensor hidden = decoder.forward(tokens, batch, seqLen);     // {B,T,D}
Tensor logits = lmHead.forward(hidden);                     // {B,T,V}
Tensor loss = Ops.crossEntropy(logits, nextTokens);         // scalar mean

for (Tensor p : parameters) {
    p.zeroGrad();
}
loss.backward();

float learningRate = 0.01f;
for (Tensor p : parameters) {
    float[] values = p.data();
    float[] gradients = p.grad();
    for (int i = 0; i < values.length; i++) {
        values[i] -= learningRate * gradients[i];
    }
}
System.out.println("loss " + loss.get(0));

Ops.crossEntropy flattens {B,T,V} internally, so the target array has length B*T. Masking makes the prediction at position t depend only on positions 0..t; that is what makes next-token training valid.

18.6 What is missing (and what was added)

The following items from the original "missing" list have been implemented:

  • Positional embeddings: PositionalEmbedding provides token + learned positional + optional segment embeddings.Padding mask: keyPaddingMask in MultiHeadAttention, TransformerBlock, TransformerEncoder, TransformerDecoder.
  • Dropout: Attention dropout, projection dropout, and residual dropout in MultiHeadAttention and TransformerBlock.
  • KV cache: TransformerDecoder.forward and TransformerBlock support KV cache for autoregressive generation.
  • RoPE: Rotary positional embeddings in MultiHeadAttention with useRoPE=true.
  • Tokenizers: BPE tokenizer in transformers.Tokenizer with special tokens, padding, truncation, encodePlus, batchEncodePlus.
  • KV cache + generation: TransformerDecoder.generate, GPTLMHeadModel.generate, BeamSearchDecoder.
  • Temperature/top-k/top-p sampling: Implemented in GPTLMHeadModel.generate and BeamSearchDecoder.
  • Repetition penalty & stop sequences: Implemented in GPTLMHeadModel.generate.
  • KV cache + generation: TransformerDecoder.generate, GPTLMHeadModel.generate, BeamSearchDecoder.
  • KV cache + generation: TransformerDecoder.generate, GPTLMHeadModel.generate, BeamSearchDecoder.
  • Weight tying: Linear.tieWeights() and shared-weight constructor.
  • KV cache + generation: TransformerDecoder.generate, GPTLMHeadModel.generate, BeamSearchDecoder.
  • KV cache + generation: TransformerDecoder.generate, GPTLMHeadModel.generate, BeamSearchDecoder.
  • Training utilities: AdamW (decoupled weight decay), LRScheduler (linear warmup + cosine decay), Trainer (gradient accumulation, logging, checkpointing), gradient clipping.
  • Mixed precision: MixedPrecisionContext with dynamic loss scaling.
  • DDP hooks: DDPHooks.DistributedDataParallel with gradient bucket all-reduce.
  • Weight loading: ModelSerializer (save/load), SafetensorsLoader, HFWeightLoader (HF name mapping).
  • ONNX export: ONNXExporter skeleton.
  • Beam search: BeamSearchDecoder with length penalty.
  • Perplexity evaluation: PerplexityEvaluator.

Remaining gaps:

  • Cross-attention: The decoder is self-attention only; encoder–decoder models need a second attention sublayer with encoder keys/values.
  • Fused kernels: No fused attention kernel, no memory-efficient attention, no flash attention (Vector API support pending).
  • Distributed training: DDP hooks are scaffolding; real all-reduce needs NCCL/MPI integration.
  • Quantization: No INT8/INT4 quantization for inference.
  • LoRA/PEFT: No low-rank adapter support yet.Full HF compatibility: Weight loading works for basic shapes but doesn't cover all HF architectures.
Precision. The transformer stack is float32. For numerical debugging, compare against a double implementation of the same shapes; layer norm's eps is fixed at 1e-5. MixedPrecisionContext provides dynamic FP16 loss scaling.
