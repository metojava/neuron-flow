1. Prerequisites

  • Java 17 or later
  • Maven 3.6+
  • Internet access (first run downloads Fashion-MNIST data)

The project uses the jdk.incubator.vector module for SIMD acceleration. Maven adds it automatically at compile and test time.

3. Building a Simple MLP

This example trains a tiny multi-layer perceptron on XOR using the core layers API. A ready-to-run copy lives at src/main/java/examples/SimpleMlpDemo.java.

package examples;

import activations.ActivationFunction;
import layers.NeuralNetwork;
import losses.LossFunction;
import optim.Adam;
import training.Trainer;

public final class SimpleMlpDemo {

    public static void main(String[] args) {
        float[][] inputs = {
            {0f, 0f}, {0f, 1f}, {1f, 0f}, {1f, 1f}
        };
        float[][] targets = {
            {0f}, {1f}, {1f}, {0f}
        };

        NeuralNetwork mlp = new NeuralNetwork(
                new int[]{2, 8, 1},
                new ActivationFunction[]{
                        ActivationFunction.linear(),
                        ActivationFunction.relu(),
                        ActivationFunction.sigmoid()
                },
                LossFunction.meanSquaredError(),
                new Adam(0.01f),
                42L);

        mlp.fit(new Trainer(2_000, 4, true, 42L), inputs, targets);

        for (int i = 0; i < inputs.length; i++) {
            float output = mlp.forwardPropagate(inputs[i])[0];
            System.out.printf("%.0f XOR %.0f = %.4f (expected %.0f)%n",
                    inputs[i][0], inputs[i][1], output, targets[i][0]);
        }
    }
}

The steps:

  1. Data — four XOR rows as float[][] inputs and targets.
  2. Topology — {2, 8, 1}: 2 inputs, one hidden layer of 8 neurons, 1 output.
  3. Activations — one per layer: linear input, ReLU hidden, sigmoid output.
  4. Loss and optimizer — mean squared error with Adam (0.01f learning rate).
  5. Training — Trainer(epochs, batchSize, shuffle, seed) passed to fit(...).
  6. Prediction — forwardPropagate(...) returns the output vector.

  • Optimizer: Adam, learning rate 0.001
  • Loss: Softmax cross-entropy
  • Epochs: 10
  • Batch size: 32 (configurable)

6. Adding a New Layer

  1. Create a class in src/main/java/layers/.
  2. Implement forward(float[] x) → output + cache for backward.
  3. Implement backward(float[] dOut) → input gradient + accumulate dW/db.
  4. Implement update(float learningRate, int batchSize) → apply accumulated gradients.
  5. Add parameterCount(), copyParametersTo/From(), copyGradientsTo/From(), zeroGrad().
  6. Add a test in src/test/java/layers/ following Conv2DTest.java or DenseTest.java.

7. Adding a New Optimizer

  1. Implement optim.Optimizer interface.
  2. The interface has one method: void update(float[] parameters, float[] gradients).
  3. Maintain internal state (momentum, moving averages, timestep) as instance fields.
  4. Follow existing patterns: SGD.java, Adam.java, AdamW.java, NAG.java.
  5. Add tests in src/test/java/optim/.
